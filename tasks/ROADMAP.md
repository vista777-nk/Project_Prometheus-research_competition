## Step 2: EQA 系统初步实现（2026.09~12）

### 研究问题

> 给定一个自然语言查询（如 "Where is the red ball?"），系统协调无人机和地面车进行空地联合探索，最终给出答案。

### 技术栈

| 模块 | 方案 |
|------|------|
| VLM | LLaVA-1.6 / InternVL2 (实验室服务器 GPU) |
| SLAM | RTAB-Map (RGB-D + LiDAR) 或 SLAM Toolbox |
| 空地联合标定 | AprilTag 地面标记 + 无人机俯瞰定位 |
| 任务规划 | 基于 LLM 的 hierarchical planning |
| 通信 | 3DR 数传 (MAVLink) + WiFi/4G (TCP) |

### 里程碑

- [ ] VLM 可回答基于单张图片的简单问题
- [ ] 车机可自主导航到指定坐标
- [ ] 无人机可自主起飞→悬停→降落
- [ ] 空地联合：无人机俯瞰引导车机导航
- [ ] EQA Demo: "红色球在哪里？" → 空地联合搜索 → 返回坐标

## Step 3: 竞赛（2027.01~08）

### 全国电赛 (TI杯)

- **时间**：2027 年 5~6 月（预计）
- **平台**：车机 + 差速底盘
- **合规要点**：MSPM0G3507 为主控；树莓派/STM32 为协处理器（仅做数据预处理，不参与控制决策）
- **准备**：提前准备好"电赛合规模式"代码分支，禁用远程通信

### CRAIC2027 空地协同赛道

- **时间**：2027 年 7~8 月（预计）
- **平台**：无人机 + 车机 + 麦轮底盘
- **优势**：EQA 系统直接支撑；服务器架构通常允许外部算力

## Step 4: 世界模型入门研究 → 毕设（2027.07~2028.06）

### 研究方向（按优先级）

1. **空地联合 3D 场景重建**
   - 无人机俯瞰视角 + 车机地面视角融合
   - 3D Gaussian Splatting (3DGS) 实时重建
   - 语义注入 (用 VLM 标注 3D 高斯)

2. **动作条件化未来预测**
   - "如果我移动到这里，会看到什么？"
   - 基于 Diffusion / Video Prediction 的 world model
   - 在仿真中先验证，再迁移实机

3. **Embodied World Model**
   - DreamerV3 风格：学习紧凑的 latent dynamics
   - 在"想象"中进行 planning

### 关键文献

- 3D Gaussian Splatting (Kerbl et al., 2023)
- DreamerV3 (Hafner et al., 2023)
- UniSim (Yang et al., 2024)
- LeRobot (Cadene et al., 2024)
