# ADR-0019: 冻结地面车参数、电气安全与 RC 仲裁基线

**状态**：已采纳

**日期**：2026-08-03

**决策者**：Phase 1.5 项目接手人、Codex

**关联**：[ADR-0003](./ADR-0003.md)、[ADR-0004](./ADR-0004.md)、
[ADR-0013](./ADR-0013.md)、[ADR-0018](./ADR-0018.md)

## 背景

电子/机械组补齐了 MC520P30、底盘尺寸、ICM42688、HC-SR04、OpenMV/云台、
电池和 IA6B 的英文答复。多数参数可直接冻结，但原答复里的 MSPM0 候选 pinmux
把 PB4/PB1 错写为 TIMA0_C0/C1，并把不支持 QEI 的 TIMG7 当成第二路 QEI。
供电建议也把未知型号的单个 5V/5A 模块同时视作 Pi 5 与全部负载的无条件电源，
缺少瞬态、纹波和舵机回灌证据。

## 决策

### 1. 机械与编码器

- MC520P30 采用 30:1 减速箱、13 PPR 电机轴编码器、AB 双相四倍频，输出轴每转
  `13 × 4 × 30 = 1560` counts；12V 空载转速按 `360±20 RPM`，不能当额定负载转速；
- 差速底盘基线为有效轮半径 0.031m、轮距 0.166m；
- X 型麦轮底盘为有效轮半径 0.0395m、轴距 0.124m、轮距 0.166m，
  `Lx=0.062m`、`Ly=0.083m`，轮序固定为 FL/FR/RL/RR；
- 有效半径含当前压缩估计，组装载荷后的里程标定可以微调半径乘数，但不得悄悄
  改写原始测量记录。

### 2. MCU 资源与超声波

- STM32 使用 TIM8_CH1..4 的 PC6..PC9 捕获 Echo，PD8..PD11 输出 Trigger；
- MSPM0 候选表改为 PB8/PB9 的 TIMA0_C0/C1 PWM、PB6/PB7 IN2、PA10/PA11
  UART0、PA9 UART1_RX。MSPM0G3507 只有 TIMG8 支持 QEI，因此两路编码器统一改成
  GPIO 双边沿软件解码；在 SysConfig 生成并编译通过前，真实剖面保持编译期失败；
- 每个 HC-SR04 Echo 都使用 2.2k 高边 + 3.3k 低边分压，约把 5V 降到 3V；
  固定按 front/rear/left/right 每 50ms 触发一路，10µs Trigger，超时上报 `0xFFFF`。

### 3. ICM42688 与共享载荷

- AD0 拉高，地址基线 `0x69`，连接前仍用 `i2cdetect -y 1` 与
  `WHO_AM_I(0x75)=0x47` 双重确认；I²C 使用 Pi GPIO2/3、`/dev/i2c-1`，100Hz 轮询，
  ±4g/±500dps；
- 安装轴为传感器 Y 朝前、X 朝左、Z 朝下。驱动发布前转换为 REP-103：
  `base=(sensor_y, sensor_x, -sensor_z)`；
- OpenMV H7 Plus 通过 USB CDC 接 Pi；OpenMV 以 50Hz PWM 直接拥有两个 PWM15S
  舵机。研究模式 Pi 只发目标，竞赛模式 OpenMV 可脱离 Pi 向 MCU 发检测结果。

### 4. IA6B 与安全仲裁

- 接收机使用 iBUS-SERVO、115200 8N1；协议帧解析和安全状态机进入两块 MCU 共用代码；
- Flysky i6 Mode 2 基线：CH1=横移/转向（右杆水平）、CH2=前后（右杆垂直）、
  CH4=偏航（左杆水平）；不把无自回中的 CH3 油门轴用于地面车速度；
- CH5 由发射机 AUX 映射到双位开关作为 ARM，CH6 映射到双位开关作为
  MANUAL/AUTO。差速车使用 CH1/CH2，麦轮车使用 CH1/CH2/CH4；
- 物理常闭急停独立于 RC。接收机失联、iBUS 超过 100ms 无有效帧、CH5 低或
  通道越界均立即刹停；恢复链路不自动解锁。只有 CH5 低→高沿且三根运动通道
  连续 3s 位于中心死区才允许解锁；
- 发射机 failsafe 必须把 CH1/2/4 设 1500、CH5 设低。CH6=AUTO 时，任一运动杆
  超出死区立即人工接管。三套接收机分别绑定，不能共用模型记忆或在实验中临时换绑。

### 5. 供电

- 车用 3S 2200mAh 25C XT60，动力母线直供 DRV8871；Pi/逻辑经受保护的 5V 支路；
- 5V/5A 模块在型号、5A 持续能力、负载电压和纹波未实测前不得验收。Pi 5 支路按
  插头处 5V/5A 预算，A2M12/OpenMV 优先作为 Pi USB 下游负载；云台必须另配
  5–8.4V 舵机 BEC，不得与 Pi 5V 同支路；
- 电池入口加总保险/反接保护，各动力、Pi、舵机支路分别加保险；采用星形配电。
  UART/I²C/PWM 必须共地，但不允许用 Pi USB 反向给 MCU 或舵机供电；
- 上车前必须记录空载/满载输出、电机启停瞬态、纹波、Pi undervoltage 与温升。

无人机 4S 5200mAh 35C 参数仅进入采购/验收表；Pixhawk、ESC、桨、GPS 和数传尚未
到货，不用地面车答复推断飞控参数。

## 后果

- 仿真、固件和部署参数统一到本次实测基线；旧值只保留在历史实验记录；
- STM32 四路超声波可以在服务器上完成，MSPM0 真实固件仍有一个明确、不可绕过的
  SysConfig/软件解码门禁；
- 单个未知 5V/5A 降压板不再被视作整车供电充分性的证据，需增加舵机 BEC；
- RC 解锁/失联状态机已由 Host 测试冻结，但第二 UART 接入控制环和接收机输出/开关
  映射仍必须在车轮架空时实测后才可落地。
