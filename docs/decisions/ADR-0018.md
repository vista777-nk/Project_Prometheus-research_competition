# ADR-0018: 确认 BOM 后按五个可插拔硬件模块冻结 Phase 1.5 边界

**状态**：已采纳

**日期**：2026-08-02

**决策者**：Phase 1.5 项目接手人、Codex

**关联**：[ADR-0003](./ADR-0003.md)、[ADR-0004](./ADR-0004.md)、
[ADR-0013](./ADR-0013.md)、[ADR-0017](./ADR-0017.md)

## 背景

早期任务书混用了 RPLIDAR A1、TB6612/BTS7960、F450/S500、其他电机/桨叶、
M8N GPS 与 3DR SiK 拓扑。负责人现已给出完整 BOM 和物理模块边界，继续保留这些
假设会让固件引脚、容器设备与装配验收相互矛盾。

## 决策

1. **共享车载智能载荷**只有一套：Pi 5、ICM42688、RPLIDAR A2M12、二维云台和
   OpenMV；它在两套底盘之间物理换装，所以差速车和麦轮车不能同时作为完整智能车运行。
2. **差速控制模块**由 MSPM0G3507 管理 2 个 MC520P30、2 个 DRV8871、4 个
   HC-SR04 和 IA6B；**麦轮控制模块**由 STM32F407VET6 管理对应的 4/4/4 个设备。
   Pi 不进入电机、编码器、RC 或超声波硬实时闭环。
3. DRV8871 是每电机一片的单 H 桥，使用 IN1/IN2；其 ILIM 是内部限流而非模拟
   电流反馈。当前 BOM 无外部采样电路，因此协议保留电流字段但上报 `NaN`，软件
   `OVERCURRENT` 不得宣称可用。
4. 无人机为 F450、Pixhawk 6C + PM07 + M9N、A2212 980KV ×4、BL32 30A ×4、
   1045 自锁桨/保护罩。IA6B 接 Pixhawk RC；915 MHz/500 mW 空中电台接 TELEM1，
   地面电台接地面站；无人机 Pi 经 TELEM2 连接 Pixhawk，并由独立 5V/5A 模块供电。
5. 无人机视觉载荷以 `DRONE_VISION` 选择 D435i CB 或双 Raspberry Pi Camera。
   D435i 路径已形成 ROS 实机入口；双 CSI 相机在具体型号、端口和 libcamera profile
   未确认前失败关闭。
6. 两台 Pi 的交付基线都是 8 GB、Debian 13/AArch64、标称 64 GB microSD；
   ROS Noetic 继续封装在 Focal ARM64 容器。
7. A2M12 串口固定为 256000 bps。车端两种 MCU 对 Pi 均呈现相同 `/dev/mcu`
   协议，PONG 身份阻止接错底盘。

## 尚未冻结的物理参数

MC520P30 PPR/减速比/最高转速、组装后轴距和轮距、两块 MCU 的最终 pinmux、四路
HC-SR04 接线、电平转换、IA6B 输出协议/通道映射、USB VID/PID/序列号、双 CSI
相机型号、二维云台舵机/供电/控制器归属及电池规格仍需上机确认。代码中的对应数值
必须标成临时值，不能从常见型号猜测。

## 后果

- 旧硬件任务书作为历史记录保留，核心计划与部署以本 ADR 和实机基线为准；
- 共享载荷换装成为实验排程约束，`SwapChassis` 只表达软件选择，不代表自动机械切换；
- 真机验收按模块进行，可先独立验证两个底盘控制模块和无人机本体，再装共享载荷；
- 所有尚缺电子/机械事实均是显式验收阻塞项，不用 mock 数据关闭 Phase 1.5。
