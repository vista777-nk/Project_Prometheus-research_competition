# 电子组待确认事项清单

> 以下问题是在通读六个技术资料文件夹（ICM42688、MSPM0G3507、OpenMV、R5底盘、
> STM32F407VET6、二轴云台）中**所有可读的源码/文档/教程/寄存器配置**后，
> 确认**在这些文件夹中无法找到答案**的问题。需要你（电子组成员）逐一确认。

---

## 🔴 最优先（阻塞固件烧录和电机转动）

### MC520P30 电机参数

1. **减速比到底是多少？** 代码里临时填了 30:1，但文档明确写了"待铭牌与台架复核"。请查看电机铭牌或用手转一圈数编码器脉冲。
2. **编码器 PPR（每转脉冲数）是 11 吗？** 这个值是在电机轴侧还是减速箱输出轴侧测量的？
3. **12V 额定转速和空载转速**各是多少 RPM？代码临时用了 330 RPM。
4. **电机/编码器的线色定义**是什么？红黑黄绿白分别对应什么（电源+/电源-/A相/B相/？）？

### 底盘机械尺寸（组装后实测，不能用仿真值）

5. 差速底盘**两轮接地点中心距**（有效 track width）是多少 mm？代码假设 180mm。
6. 麦轮底盘**前后轴距**和**左右轮距**分别是多少 mm？代码假设 wheel_base=200mm, track_width=180mm。
7. 差速 65mm 轮和麦轮 80mm 轮的**实际负载有效直径**是多少？用卡尺在装车负载下测量。
8. 麦轮的**滚轮方向**和**FL/FR/RL/RR 四轮安装位置**确认（哪个轮装哪个位置，滚轮朝向）。
9. 两底盘**整备质量**（含电机/电调/电池但不含 Pi 载荷）大约多少克？
10. **有效载荷安装位置**（Pi、LiDAR、云台等）的重心偏移？

## 🔴 最优先（阻塞 MCU 引脚冻结和上板）

### STM32F407VET6 麦轮控制器引脚

11. DRV8871 四路 IN1（PWM）和 IN2（方向）的**最终接线**是什么？目前固件 `board_config.h` 里写的是建议值（PE9/11/13/14 + PD0/2/4/6），是否已焊接？
12. 四个编码器的 A/B 相**实际接在哪个定时器的哪两个引脚**？固件假设 TIM2/3/4/5，是否已验证？
13. 四路 HC-SR04 的**具体 TRIG 和 ECHO 引脚**是什么？顺序是否按 front/rear/left/right？
14. **HC-SR04 的 ECHO 是 5V 输出**，有没有接 5V→3.3V 电平转换/分压电阻？具体方案是什么？
15. IA6B 接收机接到 STM32 的**哪个 UART 引脚**？

### MSPM0G3507 差速控制器引脚

16. DRV8871 两路 IN1/IN2 的**最终接线**？目前固件 `board_config.h` 建议 PB4/PB1 + PB6/PB8。
17. 两个编码器的**A/B 相实际接在哪个定时器**？固件建议 TIMG8(PA12/PA13) + TIMG7(PA14/PA15)。
18. 四路 HC-SR04 的**TRIG/ECHO 引脚**和**电平转换方案**？
19. IA6B 接到 MSPM0 的**哪个引脚**？
20. SysConfig 有没有**实际生成并核对过**？固件 README 说 `port_driverlib.c` 从未被编译过。

## 🟡 高优先（阻塞遥控和安全）

### Flysky IA6B 接收机配置（两底盘 + 无人机共三套）

21. **输出协议**选什么：**iBUS、PPM 还是 PWM**？iBUS 推荐，因为只需要一根信号线且是数字协议。
22. iBUS 波特率是 **115200** 吗？
23. **通道映射**（每个通道对应什么功能）：
    - 油门（throttle）= CH？
    - 转向/横移（steering/strafe）= CH？
    - 偏航（yaw）= CH？
    - 使能/解锁（arm enable）= CH？
    - 急停（emergency stop）= CH？
24. **接收机失控后各通道的默认值**（failsafe values）是什么？需要在你遥控器上设置并记下来。
25. **控制优先级**怎么定：RC 遥控器完全覆盖 Pi 命令？还是 Pi 可以抢占？
26. **解锁手势**怎么定义（比如油门最低 + 某个开关拨到特定位置 3 秒）？
27. **第三套 Flysky 遥控器**是备用还是分配给其他用途？
28. 三套接收机的**绑定关系**（哪台接收机对应哪台车/无人机）？

## 🟡 高优先（阻塞传感器驱动）

### ICM42688 IMU

29. **breakout 板具体型号**是什么？目前只知道是大目星（DAIMXA）的模块。
30. **AD0 引脚是拉高还是拉低？** SDK 代码写死地址为 **0x69**（AD0=1），但芯片默认是 0x68（AD0=0）。项目 `real_sensors.yaml` 写的是 0x68。**哪个对？** 建议在 Pi 上跑 `i2cdetect -y 1` 确认。
31. 是否使用**中断引脚（INT）**？如果用，接在树莓派的哪个 GPIO？
32. IMU 在车体上的**安装方向**（相对于 `base_link` 坐标系）？X/Y/Z 轴分别指向什么方向？

### 超声波 HC-SR04

33. 四路 HC-SR04 的**触发顺序**和**防止串扰的最小轮询间隔**是多少 ms？代码假设 50ms。
34. ECHO 的**5V→3.3V 电平转换**方案确认：电阻分压（多少 kΩ？）还是专用电平转换芯片？

## 🟢 一般优先（阻塞系统集成）

### OpenMV

35. OpenMV 的**确切型号**：是 H7 还是 H7 Plus？从出厂程序来看两者都兼容。
36. 当前**固件版本**是多少？用 OpenMV IDE 连接后查看。
37. OpenMV 与树莓派的连接方式：**USB CDC 直连** Pi（`/dev/openmv`），还是通过 MSPM0 UART 转发？
38. 竞赛用的**识别脚本**是否已经写好？目前只有出厂的颜色跟随 Demo。

### 云台

39. **舵机具体型号**（不只是"9g"）？SG90、MG90S、还是其他？
40. **供电电压**：5V 还是 6V？从 Pi 取电还是独立供电？
41. **PWM 频率**：是标准的 50Hz（20ms 周期）还是其他？
42. **控制器归属**：由 OpenMV 直接控制（如颜色跟随 Demo）？还是由 Pi 通过 GPIO/UART 控制？还是由独立 MCU（Arduino/STM32）控制？

### DRV8871 驱动板

43. **模块版本**（淘宝链接/原理图）是什么？
44. **R_ILIM 电阻值**是多少 Ω？这决定了硬件电流限制阈值。DRV8871 的 ILIM 公式需查数据手册。
45. 有没有外接的**电流采样电路**？如果没有，电流字段会一直上报 `NaN`。

### RPLIDAR A2M12

46. 雷达在车体上的**安装位置和方向**（x, y, z 坐标 + yaw）？
47. USB 适配器的**VID/PID/序列号**是多少？用于写 udev 规则创建 `/dev/rplidar` 稳定名。

### 云台安装

48. 云台在车体上的**安装位置**（底座坐标）？
49. OpenMV 相机安装在云台**上方还是下方**？

## 🔵 低优先（后续集成阶段）

### 供电与电池

50. 每台车和无人机的**电池规格**：电芯数（如 3S/4S）、容量（mAh）、放电倍率（C）、接头类型（XT60/T 插？）。
51. **5V/5A 降压模块**的具体型号？有没有测过带载输出电压和纹波？
52. **供电拓扑**：电池→降压模块→分别给 Pi/电机/舵机/传感器？共地方案是什么？
53. Pi 5 的**散热方案**（散热片+风扇？风道？）。

### 部署与网络

54. 两台 Pi 5 的**主机名**和**静态 IP** 最终确认。
55. **64GB microSD 卡**型号和耐久等级？有没有准备克隆备份卡？
56. **容器镜像传输方式**：局域网 registry、U 盘拷贝、还是 TFTP？

### 无人机（如果已准备好元器件）

57. Pixhawk 6C 的**固件版本**和完整的 **`.params` 参数导出**文件。
58. TELEM1/TELEM2 的**确认波特率**和 MAVLink 版本。
59. 电机编号、旋转方向、ESC 信号协议（PWM/OneShot/DShot?）。
60. 915MHz 数传电台的**固件版本和配置参数**，地面端 USB 接在哪台电脑上。
61. 电池、起飞重量、GPS 安装偏移。
62. 双 Pi Camera 的**具体型号、CSI 接口、镜头焦距**——或者确认只用 D435i。

## 📋 建议工作流程

按"控制模块空载台架 → 低压/限流电机台架 → 底盘离地 → 共享载荷 →
无人机无桨 → 系留/保护区实飞"的顺序推进。

以上所有问题确认后，只需修改固件 `board_config.h` 和 `chassis_params.yaml`
两个文件即可重新编译烧录。
